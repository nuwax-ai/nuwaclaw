## 一、新增 / 变更功能（重点测）

### 1. Codex 引擎

- [ ] 能正常选择并使用 Codex 建会话、发消息、收回复
- [ ] 模型切换 / 同步正常，不卡住、不崩溃
- [ ] 与 Claude Code 来回切换后仍可正常对话

### 2. MCP 预热 / OpenUI（按代码行为）

- [ ] 默认 MCP **只有** chrome-devtools；没有自动内置的 openui / ask-question
- [ ] 启动后会对这 3 个包做 npx 缓存预热：`ask-question`、`openui-mcp`、`chrome-devtools`（只预热，不等于默认启用）
- [ ] 后端下发或用户从模板添加 openui / ask-question 后，可正常使用

### 3. MCP 配置

- [ ] 新增 / 编辑 MCP 时可配置环境变量（env），保存后生效
- [ ] 粘贴略不规范的 JSON 配置也能解析；明显错误有提示

### 4. 文件服务 / 内网穿透（lanproxy）

- [ ] 应用启动后，文件服务、lanproxy 状态正常（能用、不误报挂掉）
- [ ] 异常时（服务起不来）能看出失败，而不是一直假成功

---

## 二、Bugfix（必回归）

### 1. 对话体验

- [ ] 长中文流式回复不乱码、不缺字
- [ ] 应用内输入框无红色拼写波浪线

### 2. 权限 / 提问卡片

- [ ] 权限审批弹窗完整，同意 / 拒绝后引擎有正确反应
- [ ] Ask Question（提问卡片）状态更新正常（进行中 / 完成 / 取消）

### 3. 启动与稳定性

- [ ] **安装包**冷启动不崩溃
- [ ] MCP 相关功能在安装包中可正常加载、使用
- [ ] 已配置 / 已下发的 MCP（含 openui）能正常拉起

### 4. 日志

- [ ] 当天日志不会被莫名拆成多个文件（如 `.log` + `.old.log`），方便排查

### 5. 安装与系统安全提示（按平台）

- [ ] **macOS**：安装 / 首次打开无异常系统拦截弹窗
- [ ] **Windows**：安装与运行无明显签名 / SmartScreen 异常
- [ ] **Linux（有条件）**：Codex 相关能力可跑通

## 三、建议回归（主路径）

以下非本版新功能，但链路有改动，请做一遍冒烟：

| 功能 | 冒烟要点 |
|------|----------|
| Claude Code 对话 | 新建会话 → 发消息 → 流式回复 → 取消 / 重试 |
| 会话与工作区 | 一会话一目录，切换会话配置不串 |
| MCP 启停 | 开关 MCP、重启会话后仍可用 |
| 设置页 | 引擎、模型、MCP、依赖检测页能打开且保存生效 |
| 首次消息 / 预热 | Claude Code 首条消息无明显异常变慢或失败 |
| 新建会话耗时 | 感觉上不比旧版明显更慢（尤其带 MCP 时） |
