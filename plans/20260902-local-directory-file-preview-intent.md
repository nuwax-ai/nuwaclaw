# 意图：NuwaClaw 多本地目录文件管理与预览

- 日期：2026-09-02　发起人：用户
- 状态：已接受（用户，2026-09-02）

## 问题

当前会话文件树只面向项目工作空间，不能从 NuwaClaw 中打开其他本机目录；同时文件列表一次性递归加载，目录较大时刷新和渲染成本不可控。

## 预期结果

- 用户可为一个会话打开并持久化多个本地目录，在项目目录和本地目录之间切换。
- 顶部路径控件展示当前根和面包屑，进入目录时只加载当前一层。
- 本地文件可预览、代码查看、搜索、下载、上传、新建、保存、改名和可恢复删除。
- 本地绝对路径和文件内容不进入云端；浏览器环境保持原项目目录能力。

## 受影响的用户与系统

- NuwaClaw 桌面端用户。
- `agent-electron-client` 主进程、webview preload/IPC、安全文件协议。
- `nuwax` 子模块的会话文件树、文件预览及文件操作服务。
- bundled `nuwax-file-server` 的逐级查询与静态路径边界。

## 约束

- 本地目录授权按服务域名和会话隔离并持久化，可主动移除。
- 本期目录权限不扩展给 Agent、终端或 Git。
- Windows、macOS、Linux 均需正确处理路径、权限失效和外接盘断开。
- 不提交、推送、打 tag 或发布。

## 开放问题

- Java 网关是否原样透传 `relativePath` 与 `recursive=false`，在联调时确认；不阻塞本地目录桥实现。
