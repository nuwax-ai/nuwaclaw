🖥 Nuwax ttyd 终端测试

本地 WebSocket 终端协议验证 · 仅供开发调试使用

使用方法：先在应用内启动「终端服务」，再点「连接」。
默认地址 ws://127.0.0.1:60009/ws，默认端口与应用设置保持一致。
初始目录：填写绝对路径，连接时会自动 cd 进去（需应用启动时开启 -a flag）。

ttyd 1.7.x 二进制 WebSocket 协议（子协议 tty）
方向首字节含义Payload
C→S0x7B '{'JSON_DATA（握手，必须第一条）JSON: {"columns":N,"rows":N}
C→S0x30 '0'INPUT（键盘输入）原始字节（UTF-8）
C→S0x31 '1'RESIZEJSON: {"columns":N,"rows":N}
C→S0x32 '2'PAUSE（流控）空
C→S0x33 '3'RESUME（流控）空
S→C0x30 '0'OUTPUT（终端输出）原始字节（ANSI 序列）
S→C0x31 '1'SET_WINDOW_TITLE字符串
S→C0x32 '2'SET_PREFERENCESJSON

--cwd 传参方式：ttyd 启动时加 -a flag，前端在 WS URL 附加 ?arg=--cwd&arg=%2Fpath%2Fto%2Fdir，ttyd 会把 URL query 参数追加到子进程（wrapper 脚本）的 argv。
